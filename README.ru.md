# pkt-threejs-blueprint

[English](README.md) · **Русский**

Небольшой общий слой, который наши прототипы на Three.js постоянно пишут заново: игровое время с твинами, пружины, которые не разлетаются, случайные числа с зерном и ядро панели «покрутить вживую». Подключай только то, что нужно; лишнего не тянется. Рабочее имя, пока не опубликовано.

## Стек

TypeScript 6, Vitest, обычный `tsc` (без бандлера: по файлу на модуль и есть tree-shaking). Ядро без зависимостей и без DOM. `three` необязательный peer, он нужен только слою `three/`, который будет следом. От TaoUI и TaoUX не зависит.

```bash
npm install
npm run typecheck
npm test
npm run build
```

## Что умеет

Каждый модуль подключается отдельно (`pkt-threejs-blueprint/<модуль>`), общего входа нет.

| Модуль | Что |
|---|---|
| `ease` | `Ease = (t) => number`, наши кривые (`easeOutBack` с перелётом), `smoothstep(edge0, edge1, x)` в порядке аргументов GLSL |
| `ticker` | `Ticker`: игровое время со `speed` (0 — hit-stop), `tween` и `wait` как обещания, `add`, `busy`, `clear` |
| `spring` | `spring(stiffness, zeta)`, `stepSpring` (число) и `stepSpring3` (вектор), `springMaxDt` |
| `rng` | `mulberry32(seed)`, `randomInt`; последовательность заморожена тестом, сохранённые зёрна остаются верными |
| `tuning` | `createTuning(values, { groups, storageKey })`: живые значения, сохранение только отличий от умолчаний, сброс, «скопировать как код» (`toSource`), безопасный `localStorage` |

```ts
import { Ticker } from 'pkt-threejs-blueprint/ticker';
import { easeOutBack } from 'pkt-threejs-blueprint/ease';

const ticker = new Ticker();
// каждый кадр: ticker.update(Math.min(realDt, maxDt));
await ticker.tween(0.4, (k) => (mesh.scale.x = 1 + k), easeOutBack);
```

### Дельта кадра

`dt` — время между двумя кадрами в секундах, а не частота симуляции: частота кадров остаётся экранной (60, 120, 144 Гц). Ограничь её сверху (`maxDt`) перед подачей в тикер, чтобы после фона вкладки или подвисания не прилетел `dt` в секунды и все твины не ушли в конец за один кадр. В наших проектах это `1/30`, `0.05` или `0.1`; выбирай осознанно.

Пружине одного потолка мало: она переживает только шаги короче `springMaxDt` (жёсткость 2000 при `zeta` 1: 0,0185 с). `stepSpring` и `stepSpring3` сами делят более длинный шаг; устойчивый шаг идёт одним и совпадает с сырой формулой.

## Как устроено

Три слоя по зависимостям: `core/` (ничего), `three/` (нужен `three`), `components/` (готовые блоки интерфейса поверх ядра; стили это значения нашей тёмной темы, скопированные как CSS-переменные, без TaoUI). Дизайн, решения и анализ, на котором они стоят: [docs/design.md](docs/design.md), [docs/analysis-grok.md](docs/analysis-grok.md).

## Пока нет

`three/` (помощники рендерера, указатель в NDC, `dispose`), `components/` (панель на Vue и панель на чистом DOM поверх `tuning`). Частицы, ленты, камеры, bloom и шейдеры остаются в играх намеренно: они разные, потому что разные картинки.
